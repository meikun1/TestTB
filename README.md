# TG Assistant

Личный помощник, который помогает не терять контакты в Telegram.

Идея простая: у каждого со временем накапливается куча знакомых, которым давно хотелось написать, но всё руки не доходят. Этот скрипт смотрит на твою историю переписок, понимает, кто из них «тёплый», а кто уже «остыл», и помогает написать им так, чтобы это звучало по-человечески, а не как рассылка.

Никаких массовых рассылок и спама — наоборот, всё построено вокруг того, чтобы аккаунт не словил бан и чтобы сообщения выглядели как живые.

## Как это устроено

Четыре маленьких независимых модуля, каждый делает одну вещь:

- **fetcher** — через Telethon выгребает диалоги и историю сообщений в локальный SQLite.
- **scoring** — считает по каждому контакту, насколько уместно ему сейчас писать. Тёплый / остывающий / холодный / мёртвый.
- **generator** — берёт топ контактов, подмешивает твой собственный стиль из истории и через Claude API генерит несколько вариантов первого сообщения.
- **sender** — очередь отправки с человеческим поведением: читает входящие перед ответом, «печатает» с реалистичной скоростью, спит ночью, держит лимиты.

Подробнее про антиспам — в [`docs/SAFETY.md`](docs/SAFETY.md). Про переход на свою файнтюненую модель — в [`docs/OWN_MODEL.md`](docs/OWN_MODEL.md).

## Поставить

Нужен Python 3.10+. На сервере достаточно одной команды:

```bash
git clone <repo-url> tg-assistant
cd tg-assistant
./install.sh
```

Скрипт создаст venv, поставит зависимости, разложит папки и сделает `.env` из шаблона. Дальше открываешь `.env` и заполняешь ключи:

- `TG_API_ID` и `TG_API_HASH` — берутся на https://my.telegram.org/apps
- `TG_PHONE` — твой номер
- `ANTHROPIC_API_KEY` — с https://console.anthropic.com (потом можно заменить на свою локальную модель)

Если предпочитаешь Docker или systemd — всё расписано в [`deploy/README.md`](deploy/README.md).

## Как пользоваться

Сценарий из четырёх шагов:

```bash
source venv/bin/activate

# 1. Выгрузить диалоги. При первом запуске Telegram пришлёт код в чат — введёшь его в консоли.
python -m src.fetcher.fetch_dialogs

# 2. Прогнать скоринг — кому сейчас уместно писать.
python -m src.scoring.score_contacts

# 3. Сгенерить черновики для топ-10 контактов.
python -m src.generator.generate_drafts --top 10

# 4. Запустить отправку в режиме ревью — каждое сообщение покажет перед отправкой.
python -m src.sender.send_queue --mode review
```

То же самое через `make`, если лень печатать:

```bash
make fetch
make score
make generate TOP=10
make send-review
```

Когда поверишь скрипту — можно переключить sender в `--mode auto`, он будет сам отправлять одобренные черновики по расписанию.

## Про безопасность аккаунта

Telegram не любит, когда кто-то рассылает много сообщений подряд незнакомым людям. Поэтому по умолчанию всё аккуратно:

- не больше 20 сообщений в день, не больше 4 в час
- паузы между отправками — 7–60 минут, рандомом
- ночью (0–8 утра) не пишет вообще
- первые две недели работает в режиме «разгона» — по 3 сообщения в день, постепенно увеличивая
- перед каждой отправкой имитирует «typing», иногда читает входящие
- если упал reply rate (тебе перестали отвечать) — притормаживает

Все эти ручки крутятся в `.env`. Если что-то выглядит подозрительно — sender сам откажется отправлять и напишет почему.
