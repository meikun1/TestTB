# Защита от антиспам-триггеров Telegram

Краткая карта: какой триггер закрывает какой кусок кода.

## Жёсткие триггеры

| Триггер Telegram | Защита в коде |
|---|---|
| Жалобы Report Spam | Пишем только тем, кто сам нам писал >= 3 раз (`MIN_INCOMING_MESSAGES`) |
| PeerFloodError | Аварийный стоп на 48 часов в `handle_send_error` |
| Одинаковые тексты | Хеш-дедупликация по последним 90 дням в `is_duplicate_text` |
| Ссылка в первом сообщении | `validate_draft_text` режет URL в первых 30 символах |
| Массовая отправка незнакомцам | Категории `cold` и `dead` не попадают в очередь |

## Поведенческие триггеры

| Триггер | Защита |
|---|---|
| Слишком быстрая отправка | Паузы 7–60 мин случайные + часовой лимит 4 в час |
| 24/7 активность | Обязательный «сон» 00:00–08:00, рабочее окно 10:00–22:00 |
| Идеальный порядок очереди | `SKIP_PROBABILITY=0.15` иногда пропускает топ |
| Нет имитации печати | `simulate_human_behavior`: открыть диалог → прочитать входящие → typing-индикатор |
| Резкий старт | Ramp-up: первые 14 дней лимит растёт с 3 до 20 |
| Активность в выходные = в будни | `WEEKEND_MULTIPLIER=0.5` |
| Падение reply rate | Стоп на 6 часов если из последних 15 отправок ответили <25% |
| Повторные отправки одному | Не чаще 1 раза в 30 дней одному контакту |

## Лимиты по умолчанию

```
20 сообщений/сутки максимум
4 сообщения/час максимум
420–3600 секунд между отправками (7–60 минут)
+30% случайного шума к каждой паузе
Окно отправки: 10:00–22:00 локального времени
Обязательный сон: 00:00–08:00
В выходные лимиты × 0.5
```

При ramp-up первые 14 дней:
- День 1: 3 сообщения/сутки
- День 7: 11 сообщений/сутки
- День 14: 20 сообщений/сутки

## Что НЕ защищено кодом (твоя зона ответственности)

1. **IP-адрес.** Сервер должен стабильно жить в одной стране. Не вход с разных IP параллельно.
2. **Прогретость аккаунта.** Свежий аккаунт = бан даже с этой защитой.
3. **Номер телефона.** Виртуальные номера / голосовая верификация — повышенный риск.
4. **Параллельные сессии.** Не логинься с телефона в той же стране параллельно с активной автоматикой — антифрод увидит дубли действий.
5. **Качество текстов.** Если LLM выдаёт нелепое или похожее на спам — никакие тайминги не спасут. Поэтому генератор валидируется на старте.

## Отключение в крайнем случае

Если получил PeerFlood — система автоматически встаёт на 48 часов.
Если хочешь остановить вручную: `sudo systemctl stop tg-assistant`.

После PeerFlood **не возобновляй автоматику сразу** — несколько дней попиши с этого аккаунта вручную обычным людям, чтобы Telegram «остыл».
